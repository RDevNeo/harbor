One account, all your machines

Each PC runs Harbor itself. Sign in with Google and your PCs and phones find each other: chats and projects follow you, and an agent runs wherever the work is.

Chats follow your account

Start a chat on your laptop and continue it from your desktop or your phone. The draft you're typing follows too.

Run it on any PC

Pick the PC a chat runs on, or Auto: the one with the most free memory. Projects can move between PCs, worktrees and all.

Carries on when a PC is off

If the PC a chat runs on goes off, the next message moves it to another PC with the project, and hands it back when that PC returns.

Workspaces for teams

Invite people by email to your workspace: they see and drive its PCs and chats from their own PCs and phones.

Direct and encrypted

PCs talk to each other over your own network, every connection mutual TLS pinned to each device's key. No VPN to set up.

The phone mirrors the desktop

Harbor for Android shows chats exactly as the desktop does: start chats, send photos, dictate, stop, fork, and get notified when a turn ends.

Built for agents doing real work

Everything around the chat that keeps several agents moving at once.

A lead with a team

A lead agent splits the work and hands it to sub-agents that message each other, run dev servers and wake on webhooks, while you follow every step.

Split chat panes

Drag chats side by side, up to four in any layout, each with its own composer. The layout survives restarts.

Worktrees, handled

Chats can work in their own git worktree with a readable branch name, show their pull request's status, and clean up once it's merged.

Voice dictation

Talk instead of typing, on the desktop and the phone. Transcribed locally by NVIDIA Parakeet, or by another of your PCs.

Usage limits handled

Plan limits at a glance and several Claude accounts side by side. When one runs out, Harbor switches account or waits and continues.

Survives restarts and updates

Agents run outside the window. Signed updates arrive within seconds of a release and swap in place, back to the same chat, scroll and draft.

Pull requests and issues

Pages for your pull requests and issues from gh, across every PC of the workspace.

Your own buttons and panels

Patches: a small file in a project adds buttons that run commands and panels beside the chat. Agents can write them for you.

Light by design

No Electron, no WebView: a native Slint window that redraws only what changed. Long chats keep just their last messages loaded.

Integrations

Connect the services and apps your agents need from Settings › Integrations. Sign in once and every chat gets the tools, on Claude Code and Codex alike.

  • GitHubRepos, issues, PRs; gh and git push
  • GmailRead, send and sort your mail, several accounts
  • WhatsAppRead and send messages as you
  • DiscordRead, search and send as you
  • VercelProjects, deployments, logs, docs
  • LinearIssues, projects, cycles
  • SentryErrors, traces, releases
  • SupabaseDatabase, auth, edge functions
  • ConvexDeployments, data and the convex CLI
  • Context7Up-to-date library docs
  • PlaywrightA headless browser to test web apps
  • Roblox StudioBuild and playtest places, when its MCP is installed
  • BlenderScenes and models, when its MCP is installed
  • Any MCP serverAdd your own, shared with the claude CLI

Gmail, WhatsApp and Discord run from your own PC with your own sign-in; there is no Harbor server in between. See the privacy policy.

Install

One line per system. The installer also sets up Git, Claude Code, Codex and ripgrep when they're missing, then Harbor keeps itself updated.

Linux x86_64 · arm64

$ curl -fsSL https://github.com/RDevNeo/harbor/releases/latest/download/install.sh | sh

Installs into ~/.local without sudo. glibc 2.35+ (Ubuntu 22.04+, Debian 12+, Fedora 36+, Arch), Wayland or X11. Offline: x86_64 or aarch64 .tar.gz, then ./install.sh.

Windows x64 · preview

PS> irm https://github.com/RDevNeo/harbor/releases/latest/download/install.ps1 | iex

In PowerShell, for your user, no administrator needed. Windows 10 1809 or newer. Start menu, tray icon and harbor on PATH.

macOS Apple Silicon · preview

$ curl -fsSL https://github.com/RDevNeo/harbor/releases/latest/download/install.sh | sh

Puts Harbor.app in ~/Applications. macOS 13 or newer. Not signed by Apple yet, so the command is the easy way; or get the .dmg.

Android

Download the app (.apk)

Open it on your phone and allow installs from your browser (asked once; on Samsung turn off Auto Blocker; if Play Protect warns, More details › Install anyway). Sign in with the same Google account as on your PCs: they show up by themselves, and the app updates itself.

Every download is checked against the release's minisign signature. Checksums: SHA256SUMS · Latest release · Changelog
