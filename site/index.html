Harbor

A native chat client for coding agents. Claude Code, Codex, Gemini and others, organised by repository. Written in Rust: no Electron, no WebView.

  • 0% CPU when idle
  • ~70 MB memory when idle
  • ~15 MB app binary

Recommended One command, installs and updates itself

$ curl -fsSL https://github.com/RDevNeo/harbor/releases/latest/download/install.sh | sh

Installs into ~/.local without sudo. Add sh -s -- --with-browser for the optional browser engine (about 45 MB).

Manual install

Download for Linux (.tar.gz)
  1. Extract it: tar xzf harbor-x86_64-linux.tar.gz
  2. Run ./install.sh inside the folder (works offline; it checks the files against the signed checksums)
  3. Open Harbor from your app menu

Android companion app

Read and drive your Harbor chats from your phone: start chats, send messages and photos, stop, fork. The agents keep running on your PC; the phone pairs with a desktop Harbor and talks to it directly over an encrypted connection.

Download for Android (.apk)
  1. Open the .apk on your phone and allow installing apps from your browser (asked once). If Android still refuses: on Samsung phones turn off Auto Blocker (Settings › Security and privacy), and if Play Protect warns, tap More details › Install anyway
  2. In desktop Harbor, open Settings › Phones, turn on Phone access and click Pair a phone
  3. Scan the pairing code with your phone's camera; the app updates itself from the PC after that

Or get harbor-android.apk from GitHub releases.

One universal build for Linux x86_64 with glibc 2.35+ (Ubuntu 22.04+, Debian 12+, Fedora 36+, Arch), Wayland or X11. No .deb or distro packages. Needs a coding-agent CLI such as claude, codex or gemini. Checksums: SHA256SUMS (signed with minisign) · View on GitHub

Light by design

Harbor is a native Rust app (egui). There is no Electron, no WebView, and no Node or Chromium runtime behind the app window.

0% CPU when idle

Harbor only redraws when something changes. Measured on 0.1.2: no CPU time used over 30 seconds with the window open and nothing running.

Small and lean

A single binary of about 15 MB that uses about 70 MB of memory when idle. Memory grows with what you open, not with a bundled browser.

Agents run directly

Each turn runs the agent's own CLI (Claude Code, Codex, Gemini…) headless and streams its output into Harbor. No terminal emulator or browser wrapper per chat, and the CLIs are not modified.

Survives restarts and updates

Turns run outside the window, so an agent keeps working if you close Harbor, restart it or update it, and the chat picks up where it is.

Browser only when you want it

The optional browser panel uses Servo in a separate helper process. It isn't installed by default and only runs while that panel is open.

Updates itself

New versions are checked against their signatures and swapped in place, without a restart.

Measured with Harbor 0.1.2 on x86_64 Linux, idle window. Memory varies with your GPU driver and how many chats are open.

Everything your agents need, in one native window

Every agent, one place

Claude Code (with more than one account), Codex, Cursor, Gemini, Grok, OpenCode and more. Each runs as its own CLI, and nothing stays in memory between turns.

Organised by repository

Projects in the sidebar, with chats under each one. Search everything, and finished chats move to “Settled”.

A lead with a team

A lead agent splits the work and hands it to sub-agents that message each other, while you follow every step.

Terminal, browser, devices

A built-in panel with a real terminal, a browser and your paired PCs and phones, right next to the chat.

Usage limits handled

See your plan limits at a glance. When a limit runs out, Harbor waits and continues the chat when it resets.

Pull requests and integrations

Review pull requests from gh, and add GitHub, Vercel, Linear, Sentry, Supabase or your own MCP servers from Settings.

Gmail for your agents

Optional: sign in with your own Google account and your agents can search and read your mail, reply, keep drafts, and sort it with labels, archive and trash. They do it only when you ask. Harbor talks to Gmail directly from your computer and keeps the sign-in there; there is no Harbor server in between. See the privacy policy.
