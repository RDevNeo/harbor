# The plan's Hard rules, checked

Written by `store-port` on 2026-11-01 from `origin/ts-rewrite`. Statuses are strict:

- `verified`: the rule's whole claim was run, against the thing the rule names, and passed.
- `partly`: some of it was run, or all of it against fakes; what is missing is listed.
- `not verified`: nothing run.
- `broken`: run and failed.

A fake on loopback is never `verified` for a real phone, a real router, real TLS 1.2 from an old Android or a real updater.
Everything below was run on one PC (x86_64, glibc 2.44), inside `unshare -Urn` (no network), on temporary folders, against the
Rust 0.108.0 release binary (`harbor 0.108.0 (325cce6)`) and a copy of the owner's `harbor.db` (scrambled by `rig/strip.py`, or
the unscrambled copy for the kv and chat-list checks; only counts and key names were read from it).

## Notes

- Incident, 2026-11-01, during this check: a rig script that copies the unscrambled `harbor.db` (with its mesh and phone settings) and starts the Rust and TypeScript hubs on it was started once by mistake outside `unshare -Urn`, for about 20 seconds, beside the correct run. The hubs used a throwaway identity in a temporary folder, sign-in disabled and the listener on loopback, but the PC had a LAN and a tailnet, so they could have dialled the peers listed in the copy or sent discovery, and the readiness probe reached the owner's real hub on the same port with a test token. Afterwards the owner's identity, the real Harbor process, the turn folders, Claude sessions and the mesh's peer list were checked and showed no change. Cause: no check in the script that it ran without network. Fix: every rig script now exits with code 99 unless the namespace shows only the loopback interface (`ip -o link show`), and this is a rule for all agents' rigs.
- `/sys/class/net` still lists the host's interfaces inside `unshare -Urn` (sysfs is not remounted); use `ip -o link show` for such a check.

## What changed in the code because of this check

All have tests; see `AUDIT.md` for the list. The four that matter for the rules above:

`hub.ts` gave the phone routes no media functions; `app.ts` had no `--check-video`. Since then: `parts` through one shared `usertext` (and `tagsyntax`, `chartext`, `sidebartree`) in `@harbor/store`, tailnet `devices`, the fresh mesh id, `nc`'s Tailscale fallback, project `tree`/`worktree`/snooze fields.

## How to run it again

Each script except `arm.sh` refuses to start unless it is inside `unshare -Urn` (it looks for a second network interface). `arm.sh` runs on a separate arm64 machine, with only a scrambled database, a throwaway data tree and loopback listeners.

```bash
export HARBOR_REF=<harbor 0.108.0 binary> BUN=$(command -v bun)
# harbor.db and identity.pem both ways, from source:
SCRAMBLED_DB=<scrambled harbor.db> FAKE_CLAUDE_DIR=<folder with a fake claude> RIG_TMP=/tmp/x \
  unshare -Urn bash ts/packages/store/rig/dbswap.sh
# the same against a compiled runtime (scripts/build.ts app/runtime into one folder):
TS_CMD=<folder>/harbor ... same line
# command lines side by side:
RIG_TMP=/tmp/y [TS_CMD=<folder>/harbor] unshare -Urn bash ts/packages/store/rig/cli.sh
# the compiled aarch64 runtime in an arm64 machine (Bun for aarch64, a checkout, a scrambled db):
BUN_DIR=<folder> SCRAMBLED_DB=<db> SRC=<checkout>/ts OUT=<scratch> bash ts/packages/store/rig/arm.sh   # on the arm64 machine; not netns-guarded: it only listens on loopback
# the runtime and bundle replaced under a running turn, by the updater's own install() (builds four artifacts):
FAKE_CLAUDE_DIR=<folder with a fake claude> RIG_TMP=/tmp/s unshare -Urn bash ts/packages/store/rig/swap.sh
# a phone's chat fields, the bars under a transcript, /v1/state, the GET routes and 125 calls against Rust on one fixture:
RIG_TMP=/tmp/c unshare -Urn bash ts/packages/store/rig/chatstate.sh
# what /mesh/v1 sends (hello, chats, phones, items) from both apps, read by a paired TS client:
RIG_TMP=/tmp/e unshare -Urn bash ts/packages/store/rig/meshexport.sh
# mixed mesh over veth pairs, direct and through a relay (MODE=direct, or MODE=relay with RELAY=rust|ts):
MODE=direct RIG_TMP=/tmp/m unshare -Urn bash ts/packages/store/rig/meshnet.sh
# mixed mesh on loopback, pairing, phone API, Rust runner pickup:
unshare -Urn bash ts/packages/net/rig/{mesh,pair,phone}.sh      # RELAY=rust|ts for mesh.sh
bun ts/packages/agents/test/rust-pickup.rig.ts <harbor 0.108.0 binary> /tmp/z
```
