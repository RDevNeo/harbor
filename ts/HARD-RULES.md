# The plan's Hard rules, checked

Written by `store-port` on 2026-11-01 from `origin/ts-rewrite`. Statuses are strict:

- `verified`: the rule's whole claim was run, against the thing the rule names, and passed.
- `partly`: some of it was run, or all of it against fakes; what is missing is listed.
- `not verified`: nothing run.
- `broken`: run and failed.

A fake on loopback is never `verified` for a real phone, a real router, real TLS 1.2 from an old Android or a real updater.
Everything below was run on one PC (x86_64, glibc 2.44), inside `unshare -Urn` (no network), on temporary folders, against the
Rust 0.108.0 release binary (`harbor 0.108.0 (325cce6)`) and a copy of the owner's `harbor.db` (scrambled by `rig/strip.py`, or
the unscrambled copy for the kv and chat-list checks; only counts and key names were read from it).

## What changed in the code because of this check

All have tests; see `AUDIT.md` for the list. The four that matter for the rules above:
`tls.ts` released no connection slot for plain connections (the hub went quiet after 12 plain requests);
`phone.ts` cut long tool results, wrote mentions and set `writable` differently from Rust;
`hub.ts` gave the phone routes no media functions; `app.ts` had no `--check-video`.

## How to run it again

Each script refuses to start unless it is inside `unshare -Urn` (it looks for a second network interface).

```bash
export HARBOR_REF=<harbor 0.108.0 binary> BUN=$(command -v bun)
# harbor.db and identity.pem both ways, from source:
SCRAMBLED_DB=<scrambled harbor.db> FAKE_CLAUDE_DIR=<folder with a fake claude> RIG_TMP=/tmp/x \
  unshare -Urn bash ts/packages/store/rig/dbswap.sh
# the same against a compiled runtime (scripts/build.ts app/runtime into one folder):
TS_CMD=<folder>/harbor ... same line
# command lines side by side:
RIG_TMP=/tmp/y [TS_CMD=<folder>/harbor] unshare -Urn bash ts/packages/store/rig/cli.sh
# mixed mesh, pairing, phone API, Rust runner pickup:
unshare -Urn bash ts/packages/net/rig/{mesh,pair,phone}.sh      # RELAY=rust|ts for mesh.sh
bun ts/packages/agents/test/rust-pickup.rig.ts <harbor 0.108.0 binary> /tmp/z
```
